# Week 1 — Cloud Fundamentals & Account Setup
The AWS root user is the account owner and has unrestricted access, so it should only be used for tasks that require root-level permissions. An IAM user is an identity created within an AWS account for everyday work and can be given permissions based on what the user needs to do. I created an IAM user named `kusuma-admin` for my daily AWS activities instead of using the root account. I also enabled MFA on the root account to add an extra layer of security. The AWS Shared Responsibility Model means that AWS is responsible for security of the cloud, while the customer is responsible for security in the cloud. AWS manages the security of its infrastructure, while customers must configure and protect their own resources, data, identities, and permissions. Understanding this model helps me know which security responsibilities belong to AWS and which ones I must manage myself.
